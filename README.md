# MAGASIN In ấn

Landing page của Xưởng In Ly MAGASIN Cup, thuộc hệ sinh thái MAGASIN.

- Production preview: https://magasin-cup-preview.vercel.app
- AISEE Mini App ID: `magasin-print`
- Design profile: `friendly`

## Chạy local

Đây là website tĩnh. Mở `index.html` trực tiếp hoặc chạy bằng một static file server.

## Cấu trúc

- `index.html`: landing page chính.
- `styles.css`: toàn bộ style của website.
- `components.html`: trang tham chiếu component.
- `assets/`: ảnh sử dụng trên website.
